3. WAVE STRUCTURE (How Deployment Works)
================================================================================

WAVE 0: VKS Cluster Creation
─────────────────────────────
Duration: 10-30 minutes

What Happens:
1. Cluster CRD is created from argocd-vks.yaml
2. VMware infrastructure provider observes it
3. VMs are provisioned (1 control plane, 1 worker)
4. Kubernetes components are installed
5. Worker joins the control plane
6. System pods deploy
7. Cluster becomes Ready

Success Indicator:
   kubectl get cluster argocd-vks -n kim-prod-vlryx
   Shows: PHASE=Ready

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WAVE 10: Cluster Registration to ArgoCD
────────────────────────────────────────
Duration: 2-5 minutes (starts automatically after Wave 0 completes)

What Happens:
1. RBAC Role is created (argocd-k8s-sa-role)
2. RoleBinding is created (argocd-k8s-sa-rolebinding)
3. ManagedEntity is created (argocd-vks-managed)
4. VMware Operator validates service account
5. Operator fetches cluster API endpoint
6. Operator generates kubeconfig credentials
7. Operator creates cluster secret in ArgoCD namespace
8. ManagedEntity becomes Ready

Success Indicator:
   kubectl describe managedentity argocd-vks-managed -n kim-prod-vlryx
   Shows: Phase=Ready

Verification:
   argocd cluster list
   Shows: argocd-vks-prod in the list

7. THREE WAYS TO USE THIS
================================================================================

🔧 Option 1: GitOps (Recommended)
   - Commit all files to Git repository
   - Apply argocd-app-of-apps.yaml
   - ArgoCD continuously syncs from Git
   - Re-applying is safe (idempotent)

   mkdir -p your-repo/argocd
   cp argocd-vks/ argocd-managedentity.yaml argocd-app-of-apps.yaml your-repo/argocd/
   cd your-repo
   git add . && git commit -m "Add VKS cluster App of Apps" && git push
   kubectl apply -f argocd/argocd-app-of-apps.yaml

⚡ Option 2: Quick Deployment (Test/Demo)
   - Use without Git
   - Direct kubectl apply
   - Works immediately
   
   kubectl apply -f argocd-app-of-apps.yaml

🔧 Option 3: Customize First
   - Edit the files for your environment
   - Change namespace, cluster config, etc.
   - Then deploy

   sed -i 's/kim-prod-vlryx/your-namespace/g' *.yaml argocd-vks/*.yaml
   kubectl apply -f argocd-app-of-apps.yaml
